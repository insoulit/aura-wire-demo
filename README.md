# AuraWire Demo Application

A demo application showcasing the **AuraWire** (`insoulit/aura-wire`) component package for Laravel and Livewire.

---

## ⚡ Quick Start with DDEV

Start the development environment:

```bash
ddev start
```

Run test suite for `aura-wire` package:

```bash
ddev exec packages/aura-wire/vendor/bin/pest packages/aura-wire/tests
```
